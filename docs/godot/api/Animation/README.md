# Animation API

| クラス | 概要 |
|--------|------|
| [CharacterAnimationController](CharacterAnimationController.md) | 上半身IK + 下半身8方向ストレイフで統合制御 |
| [UpperBodyIKController](UpperBodyIKController.md) | 上半身IK統合コントローラー（右腕・左手・背骨・頭部） |
| [SpinePostureModifier](SpinePostureModifier.md) | SkeletonModifier3Dで背骨姿勢（ピッチ/リーン）を制御 |
| [IKActionPlayer](IKActionPlayer.md) | Tweenベースのアクション（投擲・ドア・近接）IK軌跡管理 |
| [IKRecoilController](IKRecoilController.md) | IKターゲット位置ベースのリコイル制御 |
| [LeftHandIKModifier](LeftHandIKModifier.md) | TwoBoneIK3Dで左手の武器グリップ追従を制御 |
