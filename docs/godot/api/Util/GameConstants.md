# GameConstants

## 概要

ゲーム全体で使用されるノード名・グループ名・ボーン名・アニメーション名・パスなどの共有定数をまとめた静的クラス。

## クラス情報

- **継承**: `-`（静的クラス）
- **ファイル**: `scripts/utils/game_constants.gd`

## 定数

用途別に定数が定義されている。代表例:

- `NODE_*`: ノード名
- `GROUP_*`: グループ名
- `BONE_*`: ARPボーン名
- `ANIM_*`: アニメーション名
- `PRESET_*`: プリセットパス
