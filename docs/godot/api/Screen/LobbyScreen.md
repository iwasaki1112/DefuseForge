# LobbyScreen

**継承:** `Control`

マルチプレイヤーのロビー画面クラス。
ゲームのホスト作成、クライアントとしての参加、プレイヤー一覧表示、準備完了状態の管理を行います。

## 定数

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| `MULTIPLAYER_GAME_SCENE` | `"res://scenes/screens/multiplayer_game.tscn"` | ゲーム画面シーンのパス |
| `MAIN_MENU_SCENE` | `"res://scenes/screens/main_menu.tscn"` | メインメニューシーンのパス |

## 状態列挙体 (LobbyState)

| 名前 | 値 | 説明 |
| :--- | :--- | :--- |
| `MENU` | `0` | 初期メニュー表示 |
| `HOSTING` | `1` | ホストとして待機中（未使用？） |
| `JOINING` | `2` | IP入力画面 |
| `CONNECTING` | `3` | サーバー接続中 |
| `IN_LOBBY` | `4` | ロビー入室済み（プレイヤー一覧表示） |

## シグナル

| 名前 | 引数 | 説明 |
| :--- | :--- | :--- |
| `game_started` | `void` | ゲームが開始された時 |
| `back_requested` | `void` | 戻るボタンが押された時 |

## メソッド

| 名前 | 戻り値 | 説明 |
| :--- | :--- | :--- |
| `get_network_manager()` | `NetworkManager` | この画面で管理しているNetworkManagerインスタンスを取得します。 |

## 機能詳細

### ネットワーク管理
内部で `NetworkManager` インスタンスを生成・管理します。ゲーム開始時には、このインスタンスを親ノードから切り離して次のシーンに引き渡します。

### UIパネル
*   **Menu Panel:** ホスト/参加/戻るの選択。
*   **Join Panel:** IPアドレス入力。
*   **Lobby Panel:** 参加者リスト、準備完了ボタン、チャット（未実装）、退出ボタン。

### カウントダウン
全員が準備完了になると、ホスト側でカウントダウンを開始し、RPCを通じて全クライアントと同期します。カウントダウン終了後、ゲームシーンへ遷移します。
