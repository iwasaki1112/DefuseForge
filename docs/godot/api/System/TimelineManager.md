# TimelineManager

**継承:** `Node`

タイムライン更新管理クラス。
同一フレーム内でのタイムライン更新リクエストをまとめ（デバウンス）、不要な再計算や再描画を防ぎます。

## シグナル

| 名前 | 引数 | 説明 |
| :--- | :--- | :--- |
| `timeline_updated` | `void` | タイムラインの更新が確定したフレームの終わりに発火します。 |

## メソッド

| 名前 | 戻り値 | 説明 |
| :--- | :--- | :--- |
| `mark_dirty()` | `void` | タイムラインデータが変更されたことを通知します。実際の更新（シグナル発火）はフレーム終了時まで遅延されます。 |

## 詳細

`call_deferred` を使用して `_flush_updates` を呼び出すことで、1フレーム中に `mark_dirty()` が何度呼ばれても、`timeline_updated` シグナルは1回だけ発火することが保証されます。
これにより、複数のキャラクターやパスの変更が同時に発生した場合のパフォーマンスが向上します。
